# 词境回声 · LexiEcho

一个本地优先、用户自带 API Key 的英语语境强化工具。

它不替代背词 App：你在“不背单词”等工具学完当天词汇后，将词表或截图交给 LexiEcho；它会生成贴近日常的例句、必要语法说明、当天词汇串联阅读，以及根据个人学习反馈调整的 i+1 阅读。

## 当前功能

- 输入或粘贴词表；支持上传截图并由视觉模型提取词表，再由用户确认。
- 单词的核心含义、搭配、词形关联、生活化例句与必要语法说明。
- 两篇阅读：当天词汇串联阅读与个人 i+1 阅读。
- 对单词、句子和阅读难度添加反馈及个人备注。
- 使用 IndexedDB 将学习记录保存在当前浏览器。
- 导入与导出 JSON 学习档案；导出文件不包含 API Key 或原始截图。
- 支持 Kimi K3、DeepSeek 和自定义 OpenAI 兼容接口。

## 使用方式

本项目没有构建步骤或第三方前端依赖。将仓库部署到 HTTPS 静态站点后，直接访问根目录即可。

1. 打开“模型与数据”。
2. 选择供应商预设，填写 API Key 后保存。
3. 在“创建今日学习”中粘贴词表，或先上传词表截图。
4. 截图识别后，核对并修改提取出的词表。
5. 生成内容，阅读并保存你的难度反馈。

## 官方预设

| 供应商 | API Base URL | 默认模型 | 图片输入 |
| --- | --- | --- | --- |
| Kimi | `https://api.moonshot.cn/v1` | `kimi-k3` | 支持 |
| DeepSeek | `https://api.deepseek.com` | `deepseek-v4-flash-vision-exp` | 支持 |

页面会自动在 Base URL 后拼接 `/chat/completions`，因此设置中不要填写完整的对话接口地址。

> API Key 默认仅保存在当前浏览器会话。勾选“仅在此设备记住 API Key”后，Key 会保存在该设备浏览器中；请不要在公共设备上开启该选项。

## 本地数据与隐私

学习记录保存在浏览器的 IndexedDB 中。更换设备或清除浏览器数据前，请先在“模型与数据”导出 JSON 备份，再在新设备导入。

本仓库不会包含个人学习记录、原始词表截图或需求讨论文档。

## 重要说明

直接双击 `index.html` 可以查看界面，但 API 调用推荐通过 Gitee Pages 等 HTTPS 静态站点进行。模型供应商必须允许浏览器跨域请求；若某供应商拒绝跨域调用，纯前端版本无法安全绕过该限制。
